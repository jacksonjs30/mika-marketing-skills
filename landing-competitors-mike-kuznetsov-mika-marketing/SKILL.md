# Анализ лендинга и конкурентов (шаги 1-3) · Mike Kuznetsov · Mika Marketing

Каждый шаг - отдельный отчёт для маркетолога в документе проекта (см. скилл ads-system-mike-kuznetsov-mika-marketing). После каждого шага: 3-5 строк выводов в чат и вопрос «Утверждаю / Поправить». Следующий шаг - после ответа, если маркетолог не сказал «делай всё подряд».

Общие правила:
- Перед началом проверь память и документ проекта: если там уже есть цены, ЦА, решения - используй их, не спрашивай заново.
- Каждая цифра и факт из интернета - со ссылкой на источник в документе.
- Если ссылка ведёт не на тот продукт, о котором говорили, - сразу скажи.
- Тексты для маркетолога - коротко, по пунктам, без воды.

## Шаг 1. Анализ лендинга / брифа

Проанализируй лендинг подробно и выдели ключевые смыслы и инсайты по категориям. Формат - короткие чёткие пункты в каждой категории.

1. **Продукт.** Что предлагается, ключевые функции и выгоды, уникальность и ценность для клиента. Формат, сроки, цены и пакеты (если цены скрыты - спросить; часто их показывают на странице «спасибо»).
2. **Целевая аудитория.** Сегменты (если есть) или обобщённые группы с типичными характеристиками и ролями.
3. **Боли и проблемы.** Какие боли и трудности аудитории закрывает лендинг.
4. **Желания и цели.** Каких результатов хочет клиент, какую трансформацию обещает продукт.
5. **Образ жизни и контекст.** Окружение и обстоятельства аудитории, которые влияют на решение о покупке.
6. **Формат и условия.** Как устроено обучение/продукт, доставка, поддержка, сопровождение.
7. **Призыв к действию.** Какие действия предлагает лендинг, ключевые мотивирующие сообщения.
8. **Эмоциональный посыл и tone of voice.**
9. **Воронка и трекинг.** Путь реклама → лендинг → заявка → оплата; какие события пикселя нужны (Lead, Purchase).
10. **Юнит-экономика.** Средний чек; допустимая цена лида = чек × конверсия лид→оплата × доля на рекламу. Неизвестную конверсию брать гипотезой и помечать.
11. **Сильные стороны и риски для рекламы** (сроки, нет лид-магнита, нет гарантии, язык, трекинг, фальшивые таймеры).
12. **Предложения по сегментации** на основе этих смыслов - передаются в шаг 4 (audience-research-mike-kuznetsov-mika-marketing).
13. **Выводы** для создания маркетинговых материалов и позиционирования.
14. **Открытые вопросы к маркетологу** (чек-лист): гео и язык, бюджет и цель продаж, обработка заявок, текущие результаты.

## Шаг 2. Конкуренты

1. **Отбор конкурентов - не «первые попавшиеся», а по критериям.**
   - **Собери 15-20 кандидатов** из четырёх источников: поиск Google по ключевым запросам ниши на языке рынка (органика и платная выдача); Meta Ad Library по тем же ключевым словам (кто рекламируется сейчас); кого назвал маркетолог; рейтинги и каталоги - только чтобы узнать имя, дальше обязательно официальный сайт.
   - **Оцени каждого по 5 критериям** (да / частично / нет):

     | Критерий | Что проверяем |
     | --- | --- |
     | Тот же продукт | Та же задача и тот же формат (не просто смежная тема) |
     | Та же аудитория | Те же роли и уровень, что у нашего продукта |
     | Тот же рынок | Продаёт в нашей стране и на нашем языке |
     | Похожая цена | ±50% от нашего чека, или явная дешёвая / бесплатная альтернатива |
     | Активная реклама | Есть объявления в Ad Library сейчас; дольше крутятся - важнее конкурент |

   - **Отсев:** не тот продукт или не та аудитория - вычёркивай, даже если бренд известный. Нет официальной страницы продукта - вычёркивай.
   - **Финал 6-8, состав:** 3-4 прямых конкурента (продукт + аудитория + цена); 1-2 крупных игрока, к которым клиент пойдёт по умолчанию; 1 дешёвая / бесплатная альтернатива; приоритет тем, кто сейчас рекламируется в Meta.
   - **Покажи маркетологу таблицу кандидатов** (название, ссылка на продукт, оценки по 5 критериям, роль: прямой / крупный / альтернатива, причина) и получи подтверждение финального списка. Только после этого разбирай лендинги.
2. По каждому открой лендинг: цена/пакеты, срок, формат, для кого, главное обещание, вход в воронку (лид-магнит, консультация, форма), гарантия, ссылка.
   **Правило ссылок:** в колонке «Ссылка» - только прямая страница продукта на официальном сайте конкурента (лендинг курса / услуги / тарифы), которую ты сам открыл и где видно название и цену. Статьи, рейтинги, обзоры, агрегаторы (каталоги курсов, блоги, СМИ, Reddit) - не ссылка на продукт. Если нашёл конкурента через статью - найди его официальный сайт и страницу продукта; статью можно указать отдельно в колонке «Где нашёл». Не нашёл прямую страницу - напиши «прямая страница не найдена», не подставляй статью.
3. Сравнительная таблица «наш продукт против конкурентов» + 4-6 выводов для рекламы: свободная ниша, аргументы цены/скорости/автора, пробелы (гарантия, бесплатный вход).

## Шаг 3. Ad Library

- Официальный API Ad Library не отдаёт коммерческую рекламу вне ЕС - смотри сайт facebook.com/ads/library через браузер.
- Поиски: 2-3 ключевые фразы ниши (страна рынка и «все страны» для русскоязычной аудитории) + названия конкурентов из шага 2.
- Экономь контекст: скриншоты и прокрутка вместо полных снимков страницы.
- Таблица: рекламодатель, что предлагает, дата старта, формат и кнопка, угол.
- Признаки работающей рекламы: крутится 30+ дней, много вариантов одного креатива. Результатов Ad Library не показывает - напиши это в ограничениях.
- Выводы: какие входы живут дольше всего, форматы, рабочие углы и хуки, кнопки, конкуренция по датам (акции, дедлайны). Эти выводы - сырьё для шагов 4-5.
